# 太鼓年度总结反模式与审查清单

## 1. 绝对禁止的产品范式

- 把年度总结做成 dashboard、SaaS landing page、统计报告或卡片画廊。
- 用统一页头、浅蓝渐变、若干信息卡和说明文字复制 23 次。
- 用 marketing hero 的大标题加功能介绍替代实际年度回顾体验。
- 把服务端海报变成当前页面的 DOM 截图，或在 Final Title 重复创建分享链路。

## 2. UI 反模式

### 卡片作为页面主体

禁止：

- Card-grid 占据主要画面。
- 多张 KPI 卡并列展示 play count、歌曲数、谱面数和时长。
- “主视觉卡 + 信息卡 + 数据卡”的常规模板。
- 大面积半透明、圆角、毛玻璃空容器。
- 为缺失信息保留同尺寸空卡或空图表。

允许：

- 少量徽章、单位、辅助证据和操作控件。
- 海报内部为静态排版而使用必要的小信息区。

### 多焦点

禁止同一页同时出现多个大标题、大数字、大图表和高对比按钮。页面必须能用一个名词回答“这一幕的主角是什么”。

### 同质背景

禁止所有页面使用相同浅蓝背景，仅改变局部卡片内容。Mood 必须来自页面语义、曲绘、昼夜或颁奖空间。

### 伪场景装饰

禁止用无语义的渐变球、光斑、bokeh、装饰圆和漂浮小卡假装沉浸。圆形必须对应鼓面、波纹、灯光或轨迹。

### 容器与文字

- 禁止长日文歌名溢出、强制单行或遮挡相邻内容。
- 禁止超大页面标题挤压真正主视觉。
- 禁止按钮文字、单位或页码改变固定构图尺寸。
- 禁止横向滚动和被播放器固定控件遮挡的 CTA。

## 3. 动效反模式

- 只用 fade/slide/up 作为一页的全部演出。
- 所有元素使用相同 delay 依次上浮，形成模板感。
- 与数据无关的持续弹跳、摇晃或高强度粒子。
- 数字到位后重复触发波纹、声音或震动。
- 页面离屏后 timeline、RAF、timer、烟花、封面流继续运行。
- CSS 与 GSAP 同时控制同一关键对象，导致跳变或叠加。
- period-to-overview 覆盖层和实体页各播放一套不一致的动画。
- reduced motion 仅把动画压缩到 1ms，仍触发大量事件和闪烁。

## 4. 数据反模式

禁止直接显示：

```text
0 点亮的日期
undefined 次
null 首
NaN h
0 个样本的排名
没有有效维度的空雷达
```

无效数据应隐藏对应证据并回收空间。不得用补零、占位条、剪影卡或空容器维持对称布局。

## 5. 文案反模式

- 统计口径、实现方式和字段说明出现在演出正文。
- “本页展示了……”“根据统计……”等报告式句子。
- 标题、正文和卡片重复同一个数字或结论。
- “留下的挑战”等无法说明对象的标签。
- 为了填满空间而堆叠三段以上说明文案。
- 中日文只改单个标签，导致语气和信息结构不一致。

优先结构：一句情绪铺垫、一次数据揭示、一句记忆点收束。

## 6. 五页专项禁止项

### Opening

- 静态海报加普通按钮。
- CTA 可被连续点击并重复导航。
- 烟花、音符轨道和封面流在离开后继续运行。

### Profile

- 玩家头像旁并列称号卡、段位卡和地区卡。
- 把玩家形象缩成资料表图标。
- 使用通用页面页头抢占登场空间。

### Overview

- 多个大统计卡并列。
- 辅助数据与 `playCount` 同级。
- 改坏现有 3D 封面通道、原始旋转几何或 transition debug 状态。

### Favorite Song

- 曲绘卡、信息卡、次数卡三块分离。
- 模糊背景比真实曲绘更醒目。
- 无有效次数时保留空 metric panel。

### Final Title

- 称号仍被包在普通信息卡中。
- 玩家形象、依据文案和三项数字比称号更突出。
- CTA 提前出现，或点击时调用分享/海报创建接口。

## 7. 提交前审查清单

每个改造页提交前逐项回答：

- [ ] 一眼能识别唯一主视觉。
- [ ] 去掉所有辅助文字后，场景仍表达该页主题。
- [ ] 页面主体不是卡片或网格。
- [ ] 背景和氛围与数据语义有关。
- [ ] 动效包含可命名的语义动作，不只是 fade/slide。
- [ ] 核心数据到位反馈只触发一次。
- [ ] `0/null/undefined/NaN` 不可见且不留空槽。
- [ ] 中日文和长歌名不溢出。
- [ ] `390x844`、`720x1568`、`844x390` 无遮挡或横向滚动。
- [ ] 非活动页、后台页、reduced motion 和 saveData 不运行循环动画。
- [ ] 原有 23 页顺序、summary v4、音频和特殊转场契约未变化。
- [ ] 页面截图不会被误认为后台 dashboard 或统计报告。

任何一项失败，都不能通过继续增加阴影、渐变、圆角、卡片或说明文字来掩盖，应回到场景主角和信息层级重新判断。
