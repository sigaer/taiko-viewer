# 08 · Design V1.1 修复记录

本文件逐项记录 V1.1 的修复：编号对应 `07-v1.1-design-decisions.md` 的裁决与 V1 规范（`04-design-system.md` 旧版）的「已知未解决」K1–K10。浏览器验收的完整数据见 `09-v1.1-qa-report.md`；规范见 `04-design-system.md`（V1.1）。

**验证级别**只取三个值：

| 级别 | 含义 |
|---|---|
| 真实浏览器 | 被 `qa/run.mjs` 的某项检查或某个流程覆盖，或在 `09` 中写明看过截图（Chrome 151，生产构建，模拟数据） |
| 源码 / 静态检查 | 编译、Node 测试（`src/mock/selftest.mjs`、`src/search.test.mjs`、`src/sync.test.mjs`）、对比度脚本（`src/styles/contrast-check.mjs`）、代码阅读或 grep |
| 未验证 | 以上都没有 |

一个条目只有部分子项被浏览器覆盖时，取「主体行为」所在的级别，并在「处理」列写明哪些子项只到源码或未验证。拿不准时取较弱的级别。流程名（`palette-desktop` 等）见 `09` §4，检查名（overflow、contrast 等）见 `09` §3 与 `qa/README.md`。
