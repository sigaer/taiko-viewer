# 05 · 主要页面的设计说明

每个页面回答四件事：它为谁解决什么问题、桌面怎么排、手机怎么变、为什么这样做。组件与 token 的细则见 `04-design-system.md`。

## 0. 全站框架

**桌面（≥1100px）**
- 左侧 84px 窄轨：标志 + 六个目的地（今日 / 曲库 / 成绩 / 成长 / 社区 / 工具）；底部是语言与深浅色。
- 60px 顶栏：模块名、二级页签（并入顶栏，不另占一行）、全局搜索、同步状态、通知、账号菜单。
- 内容区最大 1480px；需要对照信息的页面用「主栏 + 320–380px 吸顶侧栏」。

**平板（768–1099px）**：窄轨保留；顶栏搜索收成图标；侧栏内容下移到主栏之后。

**手机（≤767px）**
- 52px 顶栏：标志或返回、页面名、通知、头像。
- 二级页签是顶栏下方一行可横滑的吸顶页签。
- 底栏五格：今日 / 曲库 /「咚」搜索键 / 社区 / 我的。

**依据与收益**
- 旧侧栏占 248px 且需要展开折叠菜单才能找到功能；窄轨把一级导航压到 84px，把宽度还给数据。
- 二级页签进顶栏，每个页面多出约 48px 的首屏高度。
- 搜索是最高频动作，所以桌面常驻顶栏正中，手机占底栏正中、拇指最容易够到的位置。
- 同步状态常驻顶栏：玩家打完歌回来的第一件事是同步，不该先进账号区。

**全局搜索（命令面板）**
- 触发：Ctrl K、`/`、顶栏搜索框、手机「咚」键。
- 空状态显示最近看过的歌和快捷操作。
- 歌曲结果直接带上魔王 / 里的星级、定数和我的王冠 —— 很多时候看到这一行就够了，不必点进去。
- 输入形如 `16 oxxo 180 鬼10` 的配置串会被识别为「按配置查谱」。
- 手机上全屏展开。

## 1. 今日 `/`

**问题**：旧首页的成长面、每日进展、最近成长、目标是四个纵向堆叠的大卡片，看完要滚三屏。

**已同步的玩家**
- 第一行：Rating 鼓面刻度盘（一圈 31 颗鋲，每颗 0.5）+ 六维雷达（实线现在、虚线 30 天前、关注方向用浅葱标出）｜当前目标卡（每次尝试是一个音符，朝判定圈靠近）。
- 第二行：**21 天练习谱面**。一天一拍：朱色 = 刷新成绩，浅葱 = 更稳了，大音符 = 新王冠或练成目标，山吹色连打条 = 连续游玩，判定圈落在今天。点任意一天，下方列出那天的进展。
- 第三行：接下来可以练｜社区正在聊｜活动与新曲。

**游客**：一句话说清产品 + 一个大搜索框 + 登录按钮；右侧是同一条谱面的示例，让人看到「登录之后会得到什么」。下面是不用登录就能用的四个工具。

**未绑定 / 无成绩**：标题直接说还差几步，三步清单（登录 → 绑定 → 同步）用音符表示完成状态，主按钮永远是下一步。

**手机**：刻度盘与三个数字并排；雷达在下；谱面带横向滚动并默认停在今天。

**依据**：谱面带把「每日进展」「最近成长」「连续游玩」三个模块合成一个图形，这是整个方案里唯一的签名元素。它不是装饰 —— 每个音符都对应真实的一条成长事实。

## 2. 曲库 `/songs`

**问题**：实装 / 未上架 / 其他是三个页面；筛选只有流派和难度；列表是 80px 封面的卡片网格，一屏看不到几首。

**桌面**：左侧 216px 分面筛选（上架状态、流派、魔王星级、只看有里谱、我的进度），带计数；右侧紧凑表格：歌曲、流派、BPM、五个难度的星级格、魔王定数、我的王冠与评价、上架日期。表头吸顶，列可排序。可切换封面视图。

**手机**：搜索框 + 一行可横滑的筛选条（最常用的几个直接露出），完整筛选进底部抽屉，抽屉底部按钮实时显示「查看 N 首」。列表行：72px 封面、标题、五个星级格 + 定数、右侧王冠与评价。

**依据**：五个难度的星级放在同一行的五个固定位置，眼睛可以纵向扫一列来比较，比读「鬼 ★10 / 里 ★10」的文字快得多。「我的进度」把成绩带进曲库，回答「我还有哪些没全连」。

## 3. 歌曲详情 `/songs/:id`

**原则：一个难度就是一个视角。** 切换难度后，谱面图、数据、我的成绩、玩家体感全部跟着换；地址里带 `?d=`，可以直接分享某个难度。

**桌面**
- 头部：168px 封面、标题（当前语言在上、另一种语言在下）、流派 / 上架状态 / 版本、艺术家 / BPM / 上架日 / ID；右侧「游玩练习」「收藏」。
- 难度条吸顶：每个难度一个大按钮，写着难度名、星级、定数和我的王冠；选中的被难度色填满。
- 主栏：谱面（试听 + 每小节密度条，朱色标出难点位置；谱面图；单人 / P1 / P2；分歧）→ 谱面数据（主定数最大，其余并列；五项能力雷达）→ 玩家体感（投票柱状图即投票按钮；标签条形图；提示）→ 相关讨论。
- 右侧吸顶：我的成绩（王冠、评价、成绩、良 / 可 / 不可判定条、准确率、连击、单曲 RT、次数、最好成绩的变化）+「设为这次想练」。

**手机**：我的成绩提到难度条下面第一位（在机厅里最想看的就是它）；底部固定「游玩练习 / 想练这首」。

**依据**：旧版把定数和雷达折叠在「分析」里，要点开才看得到，而它们恰恰是来这个页面的主要原因。密度条是新增的小图：谱面图太长，密度条让人先知道难点在哪一段。

## 4. 定数表、段位、攻略、称号

- **定数表 `/songs/constants`**：可排序的密集表格，每项能力后面带一根细条；点一行，右侧检视面板显示能力雷达和 75% / 95% / 99% 三个定数的刻度。手机上检视面板是底部抽屉。
- **段位道场 `/dan`**：版本是分段切换，段位是一条横向轨道（已通过的带标记）；课题曲是真实的先后顺序，所以用了序号；合格条件表把「我的最好」放在最后一列逐行对照。
- **谱面攻略 `/guide`**：难度 × 星级矩阵，格子里是攻略数量，点格子在下方出列表。它取代了旧侧栏里 50 个叶子的树。
- **称号 `/titles`**：两栏的检索列表；别名修改日志并在页面底部。

## 5. 成绩

**Rating `/play`**
- 上：刻度盘 + 走势折线（30 / 90 / 180 天，里程碑用山吹色竖线标出）｜六维哑铃图（空心点是 30 天前，实心点是现在，中间的线就是涨幅）。
- 下：构成 Rating 的成绩。前 20 首计入，第 20 行后有一条朱色分隔线，其后是「最接近入围」的成绩 —— 回答「打哪首能涨分」。可按六个维度切换排序。
- 保留「生成 B30 图片」，因为发群是真实需求。

**全部成绩 `/play/scores`**：只读为主的紧凑表格；修改、锁定、删除是行内图标，悬停才出现；补录和导入在右上。删除前用弹层说明后果（只从 Viewer 移除，下次同步会重新写入）。手机上点一行直接进编辑抽屉。

**点灯进度 `/play/progress`**：每张谱一个格子，格子边框与底色 = 王冠（全良是虹色边框），可切换成看评价；按星级或按定数分组，每组有完成度条。它替代了「歌曲进度」图片，而且每个格子都能点进去。

**练习推荐 `/play/recommend`**：两种问法分成两个模式。「平常练什么」显示相对当前能力的难度位置（90%–105% 的区间画成一个带）；「冲一个目标」按差距排序。每一行可以直接设为目标。

## 6. 成长

**成长档案 `/growth`**：页首一句话结论（「这 90 天，高速处理涨得最多」）。主栏：可切换指标的大折线图 → 关注方向的变化（一条时间带，每段是一个时期的关注方向，并保留「这不代表某项数值下降」的说明）→ 精彩时刻。侧栏：现在的我（雷达）、当前目标、想继续的话。

**这一周 `/growth/weekly`**：一句主题当标题 → 七天谱面 → 六个数字 → 亮点 / 能力变化 / 下周可以试试。先讲故事，再给数字，沿用现有周报温和的语气。

**目标 `/growth/goals`**：当前目标占主位，尝试轨迹画成柱子（不可数越少柱子越矮，最右是目标的判定圈）；右侧是「今天可以练」，每首歌的目标类型做成可点的选项。规则不变：同一时间只有一个目标，换目标时明确告知旧目标会进入历史。「放下」不是失败，文案用「先放下」。

**年度回顾入口 `/annual`**：桌面不再把人重定向回首页，而是展示五个章节的预告、二维码和复制链接；手机直接开始，并把邀请码 / 登录 / 绑定 / 同步做成清单，第一个未完成项带操作按钮。

## 7. 社区

**广场 `/community`**：桌面三栏 —— 版块（色点 + 帖子数）｜帖子流（精选 / 热门 / 最新攻略 / 最新）｜达人榜、热门标签、谱面上的新提示。版块色只出现在一个 8px 的色点上，不做彩色卡片。关联了谱面的帖子在右侧显示封面与难度：对一个音游社区来说，「在聊哪张谱」和标题一样重要。手机：版块变成横滑筛选条，发帖是悬浮按钮。

**帖子 `/community/t/:id`**：正文限制在 760px 的阅读行宽，16px 字号、1.85 行高。右栏是这帖讨论的谱面和**我在这张谱上的成绩** —— 看攻略时可以直接对照自己卡在哪。回复框吸在底部。楼中楼用左侧竖线缩进。

**发帖 `/community/new`**：左边写，右边实时预览它在列表里的样子。标题是一个无边框的大输入框；正文是段落块 + 图片块；关联谱面可选难度。手机全屏编辑，顶部「取消 / 存草稿 / 发布」，底部工具条。

**个人主页 `/u/:name`（新增提案）**：鼓面头像、称号、段位；公开范围由自己决定（公开成绩 / 只公开社区身份），本人查看时顶部有明确的说明条。

## 8. 账号与状态

**绑定 `/bind`**：从 2,200 行的档案页里提出来，变成专注的三步流程：输入 ID → 改游戏内称号验证 → 同步第一份成绩。每一步只做一件事，验证失败时说明原因和下一步（「称号还没有变化。在游戏里保存称号后，再点一次确认。」）。其他绑定方式作为次要链接放在第一步下面。

**账号与绑定 `/account`**：按主题重组为五段 —— 身份、游戏账号、登录方式、我的小咚与称号、第三方应用授权。游戏账号是一张列表而不是三张卡片，「当前」账号有明确标记。

**同步 `/account/sync`**：一个大按钮 + 三步流向示意（鼓众广场 → Viewer → 你选择的服务）+ 同步目标开关与各自的最近结果 + 历史表。失败的目标就地显示原因和重试。

**设置 `/account/settings`**：只保留真正的设置（外观含「跟随系统」、列表密度、语言、标题显示偏好、通知、本地缓存）。旧设置页里的链接回到各自的位置。

**登录 `/login`**：登录 / 注册 / 找回密码是同一页的三种模式。桌面右半边是一条示例谱面和一句话，代替通用插画。

**状态页**（见 `#/states`）
- **加载**：列表用骨架屏；整页等待用「音符流过谱面带」。
- **空**：一条空谱面 + 判定圈，标题说现状，按钮给下一步。
- **错误**：判定圈变成「不可」的紫色；文案说明发生了什么、怎么办，不道歉、不含糊。
- **权限引导**：统一为一种形态 —— 留在原地，说明差哪一步，给那一步的按钮。取代旧版「有的硬跳登录页、有的内联提示」。
