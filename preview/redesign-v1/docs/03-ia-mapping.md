# 03 · 新旧信息架构映射与功能覆盖清单

原则：**保留产品能力，重新组织入口**。本文件逐条列出旧路由去了哪里，以及每项功能在 Design V1 里的状态。没有任何功能被删除。

状态标记：● 原型里已画出　◐ 已确定位置，原型里未细画　○ 本期不改版，保持现状

## 1. 新的信息架构

```
全局      搜索（Ctrl K / 手机「咚」键）· 同步状态 · 通知 · 账号菜单
────────────────────────────────────────────────────────────────
今日      /                      个人驾驶舱；游客是搜索优先的产品入口
曲库      /songs                 歌曲（上架状态变成筛选）
          /songs/:id             歌曲详情（难度即视角）
          /songs/constants       定数表
          /dan                   段位道场（版本是切换，不是页面）
          /guide                 谱面攻略（难度 × 星级矩阵）
          /titles                称号 + 别名修改日志
成绩      /play                  Rating：走势、六维、构成 Rating 的成绩
          /play/scores           全部成绩（管理）
          /play/progress         点灯进度
          /play/recommend        练习推荐
成长      /growth                成长档案
          /growth/weekly         这一周
          /growth/goals          目标
          /annual                年度回顾入口
社区      /community             广场（版块是筛选）
          /community/t/:id       帖子
          /community/new         发帖
          /community/me          我的社区
          /notifications         通知
          /u/:name               个人主页（新增提案）
工具      /tools                 查配置、查物量（内联）+ 其他工具入口
          /tools/rt  /tools/tja  RT 计算器、TJA 定数与谱面图
账号      /account               账号与绑定
          /account/sync          同步
          /account/settings      设置
          /account/developer     开发者
          /account/support       工单
          /login  /bind          登录 / 注册 / 找回密码；绑定流程
手机专有  /me                    「我的」枢纽（底栏第五格）
```

**一级目的地从五组折叠菜单（约 40 个可见叶子，攻略展开后约 90 个）变成 6 个。** 手机底栏从「首页 / 歌曲 / 社区 / 我的 / 更多」变成「今日 / 曲库 / 搜索 / 社区 / 我的」：「更多」这个兜底桶被取消，它的内容回到各自所属的目的地；空出来的位置给了最高频的动作。

命名统一：

| 统一后的叫法 | 取代 |
|---|---|
| 曲库 | 发现 / 歌曲列表 / 歌曲 |
| 全部成绩 | 歌曲数据 / 成绩管理 / 本地歌曲数据 |
| 这一周 | 每周回顾 / 这一周 |
| 账号与绑定 | 个人档案 / 账号系统 / 账户与设置 |
| 鼓众广场 ID | 鼓众 ID / 太鼓账号 |
| 魔王（里），短写「里」 | 里谱 / 魔王（里） |
| 普通 | 普通 / 一般 |

## 4. Design V1 新增的东西（需要你确认是否要）

这些不是现有功能的迁移，而是重新设计时提出的增量。都可以单独拿掉，不影响其余部分。

| 新增 | 理由 | 涉及后端吗 |
|---|---|---|
| 全局搜索 / 命令面板 | 查歌是最高频动作，目前只能进到列表页再搜 | 歌曲可用现有曲库接口；帖子搜索需要接口支持 |
| 顶栏同步状态 | 同步是成长闭环的前提，目前要进到账号区 | 复用现有同步接口 |
| 目标独立页面 | 目标目前没有家 | 复用现有目标接口 |
| 曲库「我的进度」筛选（没打过 / 还没全连 / 还没全良） | 把成绩数据带进曲库 | 前端可用已加载的成绩合并 |
| 个人主页 `/u/:name` | 社区里点头像目前无处可去 | **需要**：公开范围设置与公开资料接口 |
| 主题「跟随系统」 | 现有只有手动切换 | 否 |
| 原生的 Rating / 进度页面 | 替代服务端 PNG，可交互、跟随主题 | 需要把图片工具背后的数据以 JSON 提供 |
