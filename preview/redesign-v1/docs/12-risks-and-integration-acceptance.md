# 12 · 遗留风险与正式集成验收清单

日期：2026-11-16　基线：Design V1.1（`c190421e`）+ V1.2 裁定（`10-v1.2-design-decisions.md`）与 V1.2 质量报告（`11-v1.2-quality-report.md`，最终一轮 368 个用例、18 个流程，错误 0、警告 0）

本文是给正式实现团队的工作文档。前半是遗留风险登记表，后半是正式集成验收清单。

原型（`preview/redesign-v1/`）是 Vite + Vue 3 的单页应用：hash 路由、纯 CSS、只用 `src/mock/` 生成的模拟数据。正式产品是 `taiko_viewer/`（Nuxt 3.21、`ssr: true`、`@nuxtjs/i18n`、Element Plus、`@vite-pwa/nuxt`，版本 1.14.0，76 个页面）。原型里的验收（`09`、`11`）都基于模拟数据，**不是生产验收**；下面每一条风险都注明了依据，没有依据的不写。

等级：**高** = 不处理会阻塞某个阶段上线，或会造成数据、链接、登录方面的回归；**中** = 影响体验或需要额外开发，但有退路；**低** = 记录在案，按需处理。
