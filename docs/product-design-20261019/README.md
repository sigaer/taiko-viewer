## 判断依据

原始 1.0.0 定位为 **My Taiko, in one place.**：首页聚合身份、成绩、真实变化、推荐、目标和成长，歌曲、谱面、社区、年度报告之间可往返。它不是将机器人命令依次做成网页表单。

本轮复用既有[生产使用报告](../../../qa-vault/evidence/viewer-usage-20261019/report.md)。报告中歌曲详情、年度报告、成绩查询的主业务请求分别为 9,281、2,499、2,361；成长档案、进度图、周报也有业务调用。请求数量不是独立用户数、转化率或留存数据。由此优先打磨已有查阅与操作路径，保留 B30、推荐、目标和开放接口，不据低样本删除功能。

参考 [Moesekai 首页](https://pjsk.moe/zh-cn/)和[音乐图鉴](https://pjsk.moe/zh-cn/music/)的信息组织与页面连续性，不复制其青绿色品牌、几何背景或卡片组件。

## 证据边界

线上以真实 Chromium、桌面和手机视口检查公开页面与登录边界；访问受限页面不借用私人会话。登录后展示使用**同一生产构件**启动本地实例，配合现有合成 fixture 与浏览器响应替换；数据库地址指向本地关闭端口，未连接业务数据库。该方式证明当前界面怎样呈现指定数据，不证明生产账号权限或真实业务提交成功。

年度报告桌面限制属于现行行为；390px 桌面 UA 和真实移动 UA 分别记录。年度报告成功内页来自当前构件的合成报告，不称为线上真实报告。浏览器模拟不替代 iOS Safari、Android WebView 或屏幕阅读器实机验收。

进度图和绑定验证已完成的修复作为基线接受，不重新诊断历史错误。本审计不改变现有发布结论，不新增发布 Gate。

## 本次评审需要确认的设计选择

1. 红／青鼓点与冷白底是否符合 Viewer 的长期气质。
2. 首页以身份、当前目标、具体变化和推荐接续为主，年度活动降为次级内容。
3. 歌曲页使用一个难度选择统领谱面、试听、成绩和攻略，手机优先找到谱面操作。
4. 练习、成长档案、周报和歌曲进度图放进同一导航家族，保留现有路由与数据语义。

评审通过后再实施；本目录中的选择尚不代表已批准或已上线。
