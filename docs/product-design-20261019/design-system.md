# Viewer 统一设计系统提案

## 方向与取舍

定位：太鼓玩家的个人主页、谱面与成绩工具、练习和成长平台。风格采用**红青鼓点、清晰练习界面**：红色对应主动动作与咚，青色对应导航、可读变化与咔；曲绘提供内容情绪。中性背景偏冷白，避免沿用米棕色主页与高饱和素材彼此割裂的关系。

品牌记忆点限定为一组鼓点／节拍结构。在训练流程中，四个节点表达真实的“选曲→确认目标→更新成绩→确认变化”；普通页面不铺满装饰粒子、玻璃卡片或假统计。原型中的简化标记和字标属于方向研究，不代表替换正式 Logo 已获批准。

比较过三条方向：现有暖色整理、Moesekai 式高装饰内容站、红青练习界面。推荐第三条，因为它同时服务谱面识别与长时间查阅。保留现有方向的亲和力，减少厚阴影、反复套面板和大面积营销介绍。

设计检索工具给出的两组结果分别偏企业落地页和 3D 游戏展示，均未贴合本产品；未直接采用其配色、字体或动效。以下选择来自当前页面、太鼓视觉语义和既有产品目标。

## 色彩与语义

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#F3F7F8` | `#12232C` | 页面底色 |
| `surface` | `#FFFFFF` | `#1B323E` | 表单、主任务、弹窗和必要面板 |
| `ink` | `#192F3B` | `#F2F6F8` | 正文、标题、关键数据 |
| `muted` | `#526773` | `#B0C3CC` | 次级信息，保持可读 |
| `line` | `#D7E1E5` | `#415966` | 非交互分隔线；不单独承担控件识别 |
| `control-border` | `#81959F` | `#7D99A8` | 需要明确边界的控件，与装饰分隔线分开 |
| `don` | `#C83E36` | `#FF8E7D` | 主操作、当前任务标记 |
| `don-soft` | `#FFF0EC` | `#442E30` | 活跃导航、轻量提醒 |
| `ka` | `#077680` | `#75CED6` | 链接、选中范围、主要数据曲线 |
| `ka-soft` | `#E5F4F5` | `#193E48` | 选中背景、说明区域 |
| `success` | `#25744C` | `#96D6AC` | 已确认完成，与文字／图标同用 |
| `gold` | `#F2BD52` | `#F2BD52` | 称号、少量庆祝细节，不承载白色小字 |

浅色主按钮 `don / white`，深色主按钮 `don / #322124`。普通文本组合目标至少 4.5:1，大号文字与必要图形至少 3:1；具体实测值见 `contrast-validation.json`。装饰线可较淡，输入框边界、焦点与禁用态需分别验证。

难度保留玩家熟悉的语义：简单、普通、困难、魔王、里谱继续有各自颜色，必须同时显示难度名和星级。成绩冠位、社区徽标不重新定义含义。品牌色与业务颜色使用独立 token，不能把红色目标按钮当作“魔王难度”证据。

## 字体与中日文

| 角色 | 字体方向 | 字号／行高 | 字重 |
| --- | --- | --- | --- |
| 品牌、主要标题 | `Noto Sans SC` / `Noto Sans JP`，系统 CJK 无衬线回退 | 桌面 32/40，手机 24–28/34–38 | 700–800 |
| 特定首页一句话 | 同标题，不使用大段超粗文字 | 桌面上限 36/46，手机上限 30/40 | 750 |
| 区块标题 | 同标题 | 20–22/28–30 | 650–750 |
| 正文、输入内容 | 系统无衬线，包含 PingFang、Hiragino、Yu Gothic、Microsoft YaHei 回退 | 16/26；日语约 16/28 | 400–500 |
| 列表、密集表格 | 同正文 | 14/22 | 400–650 |
| 时间、来源、次级标记 | 同正文 | 12–13/19–21 | 400–650 |
| 分数、Rating、对齐数据 | `DIN Alternate` / `Bahnschrift` / 正文字体回退，`tabular-nums` | 按角色 14–36px | 600–750 |

原型使用本机可用字体，不下载或打包新字体。正式实施需先验证授权、CJK 体积与回退几何；不以跨站字体加载作为首屏依赖。

中文和日文通过 `lang` 切换字体栈与行距。标题自然换行，不能用强制 `<br>` 或整段不换行制造固定构图；长日文曲名保留完整可达文本。汉字不做大字距和全大写装饰。数字与单位之间使用正常空隙，日期按 locale 格式化，业务日继续使用 Asia/Shanghai。

导航、页标题、面包屑、提示、弹窗、复制反馈和元信息一起翻译。日语页面可保留歌曲原名及必要的国服说明，不能因页面主体翻译完成而遗漏中文导航元信息。

## 间距、页面宽度与网格

基础间距为 4px：4、8、12、16、20、24、32、40、48、64。控件内部 8–12，面板 20–24，页面主要区块 28–40。只有真正的独立任务才使用完整面板；连续列表用行、分隔线和标题组织。

| 视口 | 页面结构 | 页面边距／列间距 | 核心行为 |
| --- | --- | --- | --- |
| ≥1280 | 224px 侧栏；内容容器最大 1280px，内部 12 列 | 外边距 40，列间距 24 | 主要区域 8列，辅助区域4列；不把每块强制等宽 |
| 1024–1279 | 196px 侧栏；内容采用 8 列 | 外边距 26，间距 20–24 | 歌曲、训练可提前改为纵向，避免窄三栏 |
| 768–1023 | 8 列；保留可收起的导航区域 | 外边距 24，间距 20 | 主任务全宽；辅助内容转下一行 |
| 320–767 | 单主列，局部 4 列网格，底部5项导航 | 320宽用12边距，其余16，间距12–20 | 按任务重排；筛选可折叠；安全区计入底部留白 |

原型主要检查 360、390、768、1440 宽度。320、横屏、200% 缩放和真实浏览器工具栏伸缩属于实施验收项。不要把小视口排成缩小的桌面三栏。

## 组件规则

| 组件 | 统一规则 | 保留的能力 |
| --- | --- | --- |
| 导航 | 桌面单层主领域加少量子导航；手机最多5项；当前页有文字、颜色和位置标记 | 现有深链接、返回、语言切换、年度设备策略 |
| 按钮 | 一组动作一个主要按钮；高44px，圆角8px；文字动词准确；危险操作独立语义 | 所有合法提交、取消、重试、防重复、权限判断 |
| 表单 | 标签常驻；默认项可直接执行；高级项渐进展开；输入错误贴近字段 | B30 参数、推荐模式／数量／维度、进度图全部选项 |
| 面板 | 主任务圆角12–14px；辅助内容优先无面板；一层容器，不嵌套重复标题 | 已有功能组件内部逻辑 |
| 表格 | 桌面关键列优先，数字对齐；手机成绩行呈现曲名、难度、成绩、冠位，详情展开 | 完整字段、编辑／锁定／导入；开发者字段表可局部横滚 |
| 图表 | 数据与刻度主导，标题准确；颜色不单独区分；提供文本摘要和可达数值 | 冻结测量、现有时间范围、点选择、缺值断线和单位 |
| 弹窗 | 标题写实际决定；Esc 关闭、焦点圈定并返回触发处；手机必要时底部抽屉 | 目标选择与替换确认，绝不点击推荐即自动设目标 |
| 媒体 | 预留曲绘尺寸；明确播放器／图片／下载的去向；未知音频时长显示“—” | 三种试听音轨、分支谱面、音频失败降级、独立练习播放器 |

图标使用现有 SVG 系统或同一套线性 SVG，不以 emoji 混搭。默认阴影仅 `0 12px 32px #193C4D0A` 用于浮起的主任务区域；深色用表面差异与边线，不叠加重阴影。

## 状态与反馈

| 状态 | 表现 | 下一步与边界 |
| --- | --- | --- |
| 初次加载 | 保留页标题和上下文，内容区域骨架 | 减少动态效果时用静态占位 |
| 刷新中 | 保留同一账号、同一绑定的有效内容，局部 busy | 切换身份先失效旧内容，不把旧账号当缓存继续展示 |
| 未登录 | 说明这个操作可获得什么，一个登录主动作 | 保留返回路径、歌曲与难度；公开谱面继续可用 |
| 未绑定 | “绑定鼓众 ID”及简短解释 | 进入既有绑定流程，不改验证要求 |
| 已绑定无成绩 | “更新成绩后查看推荐与成长” | 不显示0分、0能力或伪造记录 |
| 记录稀疏 | 显示已有记录和实际覆盖时间 | 无测量点／缺失事实不推断未游玩；事实最多90天与长期测量分开解释 |
| 读取失败 | 区域内错误、重新读取；其他可用区域保持可操作 | 不自动重试写操作，不显示原始路径／错误对象 |
| 业务拒绝／冲突 | 保留具体原因与已有有效输入；必要时读取权威状态 | 沿用0.86.2的绑定状态隔离，不把请求取消当服务端撤销 |
| 图片生成 | 使用真实 loading 和响应；成功后预览、分页、保存 | 不绘制没有后端依据的百分比；失败保留筛选条件 |
| Goal 完成 | 用服务端完成证据展示前后变化，一个下一步 | 不把选曲、打开播放器或模拟同步当作真实完成 |
| 非紧急成功 | 区域内状态变化；必要时一次短消息 | 使用 `role=status`，不重复弹出“成功” |

开发者文档仍保留版本、字段、权限、错误码、示例和必要的技术解释；“去实现文案”不用于删减真正的接入契约。

## 动效原则

按压反馈80–100ms；选中与颜色变化140–180ms；局部展开180–240ms；路由变化不等待装饰动效。只动 opacity／transform，避免页面整体重排。目标完成最多一次短强调，不能自动连续庆祝或妨碍下一操作。

尊重 `prefers-reduced-motion`，取消位移、缩放、连续骨架和背景动画；用静态状态与文本传达同样信息。年度报告沿用自身已有的 reduced-motion 机制和用户触发音频，不以普通页面规范重写故事分镜。

## 复用与样式迁移

统一定义 Viewer 语义变量，再映射到 Element Plus 的主色、文本、边界与状态色；先消除默认蓝色与暖色按钮并存。主导航、页头、状态、表单外观共用一套样式源。

业务组件保持原有 props、事件和数据来源；先改变容器与排版，再逐页移除覆盖旧 token 的硬编码颜色。不要同时长期保留“新首页皮肤”和“旧工具皮肤”两套权威变量。按页面分批过渡时记录剩余覆盖项，迁移完成后删除临时适配。详细范围见 [迁移计划](migration.md)。
