# Viewer V2 视觉原型修订

2026-10-20，Asia/Shanghai。设计提案，待视觉评审。此次修改以**信息成组与阅读节奏**为核心：降低连续开场和卡片的竞争，让谱面、推荐与可信变化承担内容重点。保留红青候选品牌色、现有数据与操作语义。

先看[同视口 V1 / V2 对照](compare.html)，再打开[可操作 V2（从歌曲页开始）](v2/index.html?view=song)。两者都可直接从本地浏览器打开，无需安装依赖。顶部评审栏保留四页、九种状态、中日文和深浅主题切换。

[保留 V1](v1/index.html?view=song)与[原始交付](../prototype/index.html)文件完全一致；[保存清单](v1-preservation.json)记录八个文件的 SHA-256。原审计、设计系统与迁移资料继续保留，本说明只修订四页的视觉关系，不重开全站审计。

首页手机端选择先展示具体变化，再展示当前目标，因此推荐比 V1 更靠后；它没有要求所有访客先处理训练。未设目标时仍可查看变化、推荐与曲库。这里保留个人主页的阅读顺序，不以“所有内容都提前”为目标。

歌曲手机端保留完整曲名、14px 元数据与可点难度；没有通过缩小文字压缩首屏。中文标题在版本括号前获得自然换行点。手机谱面区域并未整体前移，播放器入口位置与 V1 接近；桌面则解决了标题半幅挤压和谱面主次不明。

## 本次空间与组件规则

沿用原交付色彩、字体族、导航和基础网格。页面常规文字采用 14–16px；歌名、目标与变化数值按其作用突出。辅助内容通过取消底色、彩色标签、过重字重、重复边框和阴影降低重量，保持可读颜色。

- 同一事实内部使用约 5–12px 距离，例如曲名与原名、名称与成绩；同组控件和条目用 14–24px。
- 新主题通常使用 28–44px；桌面主内容与阅读侧栏使用 48px。上述间距按关系选用，没有给每个元素统一扩边。
- 谱面、趋势图使用主要白色阅读面；目标、最近变化、讨论和里程碑不再默认各有白卡。结果行用内容对齐和单条分隔线组织。
- 常用操作保持直接可见；检查目标、打开播放器、查看推荐保留明确按钮。更换／取消目标、推荐数量和图片导出收进具名展开项，未删除。
- 难度、推荐模式和时间范围以文字和选中线表达当前项，不把所有选项做成实心按钮。主体按钮、页签和表单仍保留至少 44px 高度；动效继续复用原来的减少动态效果设置。

这是四页共享的层级规则，不要求将所有现有页面一律去卡片化。后续若实施，应复用原迁移方案，先落实歌曲和练习，再同步首页与成长；本轮没有修改生产组件。

## 视觉评审与保留行为

逐页查看了两版桌面、手机首屏，以及 V2 的长页和展开状态。当前判断是：歌曲页的重心更集中，练习少了多次开场，首页从训练宣传转回个人记录，成长的事实与曲线更直接。这个方向是否足够舒适，仍需要用户实际看页；技术检查不替代这个判断。

独立原型保留难度切换、普通／目标推荐来源限制、目标选择和确认、先更新成绩再检查、取消目标、图表范围／指标／数值表及中日文切换。[原型检查记录](prototype-check.json)只确认这些展示和交互仍可访问。播放器、同步、社区等沿用 V1 的演示衔接，不连接生产接口，不证明真实业务写入成功。

原生产代码、API、数据库、认证、版本与部署均未调整；没有新增埋点、依赖或重跑后端业务套件。下一步只评审这组页面的视觉方向，再决定生产实施。
