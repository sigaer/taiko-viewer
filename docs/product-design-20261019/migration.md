# 组件复用与实施计划

## 范围与决策边界

这是一份待评审的 UI 实施顺序，不新增发布 Gate，不要求提升到任何路线图版本。每个阶段可以按实际影响面独立评审。当前阶段仅交付文档与独立原型，未实施以下改动。

不改变 API、算法、数据库、身份、权限、Source、Publication、历史测量或目标判断。不删除现有推荐列表、谱面导航、目标确认、成绩维护、年度故事、社区发布与开发者接入能力。

## 分阶段顺序

| 顺序 | 交付范围 | 回归风险 | 完成标准 |
| --- | --- | --- | --- |
| 设计评审 | 评审本目录的方向、页面层级、路由家族与状态 | 把原型效果误认作已实施 | 用户明确接受方向；需要调整的选择有记录 |

| 第二阶段：曲库与歌曲 | 列表工具栏、歌曲详情与难度上下文、谱面操作 | URL难度丢失、音频重置、分支谱面、下载或UGC不可达 | 推荐→详情→播放器→返回仍有原曲、难度与列表条件；缺资源正常降级 |

这不是要求同时重写所有页面。可先迁移高频页面，临时旧样式覆盖登记后按页消除。若某阶段发现数据／权限缺陷，单独记录和处理，不把设计阶段升级为后端重构。

## 设计验收标准

### 共通可用性

- 每页只有一个明确的主标题；标题、说明、卡片头不机械重复。
- 当前太鼓账号和谱面难度可辨认；切换后没有旧身份成绩、通知、busy状态或目标残留。
- 核心操作可通过键盘、触屏完成；弹窗Esc和焦点返回有效；不依赖hover才能发现。
- 手机主要触控命中区不小于44×44，危险动作与主要动作有足够距离；底部和弹窗包含安全区。
- 320、360、390、430、768、1024、1440宽度无整页横向滚动；允许代码和确需多列的表格在自身容器滚动。
- 200%缩放、中文长昵称、完整长日文曲名、缺翻译键、空值和大数字不破坏布局。
- 原始来源、法律／隐私说明、记录范围、错误原因和下一步不因“简化文案”被删除。

### 核心流程

| 流程 | 最低检查 |
| --- | --- |
| 访客搜歌 | 搜索、清空、无结果、失败、进入详情、返回原查询 |
| 推荐→Goal | 完整普通／目标列表；token／难度资格；明确确认；重复点击；替换／取消；409／失效；切换账号；合法主动重试 |
| 同步→反馈 | 更新成绩与检查目标是显式行为；未更新／无变化／不能确认／严格完成分别表达；同事实去重 |
| 歌曲／谱面 | 全部实际难度、单双打／变体、分支音轨、缺音频／图片／分析、播放器和完整图、下载、UGC与讨论 |
| 成长／周报 | 无数据、单点、稳定、多点、缺值、部分范围、90天事实与365天测量区分、点选择和返回歌曲 |
| 图表工具 | B30全参数、推荐导出、进度四类与分页、图片读取／保存失败、刷新保留选择 |
| 账号／绑定 | 复用0.86.2既有迟到响应／账号／输入／目标／卸载／finally检查，不为换皮重写处理器 |
| 年度 | 桌面提示、手机门槛、缺数据、排队、失败／重试、成功故事、音乐、退出、分享与撤销；实机验证 |
| 社区／开发者 | 公开读取、登录引导、关联跳转、发布和隐藏；示例复制、长路径、局部滚动、正确权限与失效说明 |

### 视觉一致性与事实准确

主按钮、焦点、表单、表面、字体和间距按统一token验收。普通正文对比度目标4.5:1；控件边界和焦点另测。图表有摘要、单位、图例或直接标签及可达数值，不能只靠颜色。减少动态效果时内容与操作全部保留。

UI迁移前后，对同一隔离合成样本比较关键字段、排序和图片输出；不改变Rating、推荐算法、Goal判断、冻结测量和事实归因。性能只检查本次UI是否带来新增重复请求／明显布局跳动，不新增埋点或重新统计生产使用。

原型当前的浏览器结果只证明静态展示和局部演示交互，不构成上述业务、真机或无障碍完整验收。实施时复用已有测试与隔离方式，新增检查只针对真实变化和风险。
