预览工作树 `/var/tmp/viewer-song-preview-20261020`，分支 `design/song-detail-preview-20261020`。基于 `55a979a`；开始时核对远程 main 为 `1c522c1`（0.86.2），设计分支领先 3 个提交，无落后。原设计资料、V1/V2 原型和歌曲页历史截图保留。最新空间要求已提升为公共默认，取代此前“仅首页限宽”的边界。本轮不合 main、不部署、不改版本。

## 打开与评审

统一入口 **http://127.0.0.1:3208/__review**，可连续进入真实 Nuxt 页面、切换合成身份、查看前后截图。启动命令和远程端口转发见 [预览 README](../../preview/song-detail/README.md)。这里没有另一套 HTML 原型。

先按歌曲列表 → 歌曲详情 → 推荐 → 个人资料浏览，再看首页的宽度对照。推荐点击“查看推荐”取得完整 20 条合成结果；展开选项可查看维度及同批图片。目标确认仍用原组件，保存被只读预览拒绝，不代表业务提交成功。

## 空间与内容

歌曲列表采用曲绘与文本组成的紧凑对象行；60 条实际目录样本可连续加载。详情继续以谱面为主，节选固定窗口跳过重复图片标题，展开后保留原 PNG 全部内容；没有智能裁图或新渲染器。原难度、成绩、播放器、完整谱面、下载、分支音轨、分析、目标来源及讨论入口保留。

普通推荐将数量和主操作放在一起，维度／图片按需展开并显示当前摘要，结果提前出现。没有开放精确目标或未玩目标。资料页将绑定列表放在手动资料管理前，帮助、挑战和具体错误保留。`profile.vue` 的处理器与基线完全一致，script 只新增静态 `contentLayout: "reading"` meta；真实组件异步保护回归另附。

兼容检查发现推荐、B30、趋势和词云原先使用了不能自动解析的 `AccountToolGate` 名称；改为显式导入已有组件，保留原门禁条件和 API，不另造认证逻辑。未登录提示原本把段落与操作区放入 Element Plus 的段落插槽，现改用 description 属性和外部操作区，避免非法 HTML 引起的 hydration 不一致；登录条件与目的地保持。

## 公共空间规则与首页对照

默认 `standard` 1000px；`wide` 1180px 用于多列成绩、定数、课题及谱面与成绩并排；`reading` 800px 用于主要表单和长篇正文。通过现有 route meta 的 `contentLayout` 指定少量例外，未指定即默认；没有第二套路由系统。独立 story／false 布局不经过普通容器，播放器 `immersive` 保留自己的 1440px 工作区、固定比例 iframe 和全屏。

标题、面包屑、提示与正文共用同一容器，容器自身不增加 padding；外围只由 `main` 的 gutter 提供，手机 20px、桌面 `clamp(24px,3vw,48px)`。可见面板保留必要的内部 24／20px，推荐行和成绩行不随外围留白增高。收敛首页、社区、成长、周报、资料、认证、发帖、指南与授权页的原局部宽度，移除授权页重复水平 padding。

1440 下默认页两侧各 96px，表单／正文各 196px，密集页因实际可用空间限制为 1105.6px；1920 下分别封顶 1000／800／1180px。每一个页面的类型与例外原因均列在唯一迁移表。

### 首页宽度补充

同一数据、同一 Linux Chromium、1440×1000 记录在 [调整前](home-width-before.json) 与 [调整后](home-width-after.json)。`main` 现有内边距继续承担最小页边距，现已由公共 `.viewer-content` 提供 `width:100%;max-width:var(--viewer-content-standard);margin-inline:auto` 居中；首页原来的局部上限已移除，无额外大 margin 或嵌套 padding。

## 范围与验证边界

唯一 [迁移表](migration.md) 覆盖实际 73 个页面文件，明确区分公共适配和内容完成。成绩／B30／进度／成长／周报为下一批；首页和 My Taiko 深层状态再下一批；社区／开发者／设置／帮助及其他入口随后处理。管理后台仅兼容，年度独立演出、时间线和分享素材未重排。

截图是 Linux Chromium 的模拟视口，DPR 1；不是用户手机实测。字体通过 CDP 的 `CSS.getPlatformFontsForNode` 记录：本机中文实际 Microsoft YaHei UI、日文 Hiragino Sans，数字和按钮随语言使用对应字体；未新增字体包。详见 `after-fonts.json`。

公开目录为保存的公开 GET；个人账号、成绩、20 条推荐和有限历史为合成 fixture。未知 API 不转发，写入 405；只有既有只读目标预览返回确认 DTO。静态合成推荐 SVG 不验证生产图片生成。社区为合成空社区，成长／周报为有限历史；进度页只提供合法空选项 fixture，不生成进度图。不宣称覆盖真实长历史和运营数据。

初轮兼容截图中，进度选项 fixture 缺失的 404 触发现有 `resolveViewerError` 在异步 catch 中调用 `useI18n` 的异常，堆栈记录于 `qa-4b9f45014c31`；更早等待失败记录在 `qa-a281c221da3d`、`qa-912515be05d3`。该处理器与基线相同，本轮未修改，不能把空选项兼容通过理解为进度失败路径已修复。后台登录只补预览未登录响应及非本地化截图路由；没有变更认证逻辑。后台登录按独立登录入口检查外观，不验证普通用户页面切换后台的认证生命周期；初轮连贯截取仍出现过无 JS 异常但等待 Nuxt 挂载标记超时，证据保留于 `qa-20dd571069d9`，不据此声称后台流程完成验收。

本轮仅执行布局／控件浏览器检查、推荐身份保护、资料绑定真实组件异步矩阵。未重跑算法、灾备或生产数据套件。最终检查记录见 `validation.json`。视觉是否舒适以统一入口中的真实页面和对照图评审；无溢出和 JS 检查只作辅助证据。
