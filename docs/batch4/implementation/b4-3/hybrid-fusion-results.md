# Hybrid 融合结果与决策

真实M4相对于M0的稳定增益尚未测得；当前既没有真实正结果，也没有真实负结果。保留M0是等待证据期间的产品策略，不是宣称真实实验已经失败。

实现：先由训练用户OOF的y−M0构建条件残差，再按ESS/条件方差收缩为CohortResidual；Hybrid=M0+λ×CohortResidual。λ由外层train内部3折完整用户CV选择，网格0/0.25/0.5/0.75/1，用户宏MAE最小、同分选小λ。所有归一化、群体、噪声与权重选择只在训练内。分位校准留出用户的全部记录也从λ选择中排除。

不足时输出cohort_unavailable并完整回退M0点和分位校准。CV有充分证据但选择λ=0时也回退M0，而不会把这种模型选择误称为群体不可用。

定向测试覆盖正信号、λ=0、同分选择、用户分组不变性、校准用户排除、测试标签投毒以及未知区间；这些是实现验证，不是实际预测效果报告。
