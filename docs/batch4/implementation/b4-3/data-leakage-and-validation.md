# 数据泄漏与验证

## 输入边界

只读了本机 Bot 的源码来固定 M0；没有访问另一台设备的 Taiko Agent，没有读取 IDE 中的真实玩家文件。合成对象仅驻留实验进程；没有导入账号、复制生产数据或连接 DB。

画像历史与目标谱面集合完全分离。Rating、六维、成绩结构只从可见的18个历史谱面构造；稀疏画像只有4个，冷启动为0个。全部历史 visibleAt 在 asOf 之前。核心显式日期固定；没有从成绩更新字段推断真实演奏时间。

`personal_fixture.py` 将核心源码全部 Python 文件的路径与内容规范散列，与 m0-source.json 比较，任何偏移在 import 前拒绝。可重放测试比较完整合成输入及 M0 结果的 SHA256，不打印成员数据。

## 精确分折

唯一用户、唯一家族分别按 SHA256(`b43/{namespace}/{identity}`) 排序，再以排序下标 mod3 均衡分折。所有用户快照/谱面始终跟随同一用户折。分组身份而非成绩决定折。

- Cross-user：测试用户折=f；train 排除这些用户的所有谱面，不排除家族。
- Chart-family：测试用户折=f 且家族折=f；train 排除整个用户折以及整个家族折。
- Combined：测试用户折=f 且家族折=(f+1)%3；train 同时排除整个用户折与该家族折。

由于严格要求“测试用户全部谱面不得进入训练”，密集合成样本上的 chart-family 也带用户 embargo。它与 combined 是两种预先固定的联合留出面板，**不是两个独立的泛化证明**；不得合并成重复独立证据。没有纯家族但共享测试用户的捷径。未见家族没有同谱面/家族群体，当前 M1–M4 点预测按协议回退个人。

最初哈希直接取模导致3个家族可能集中同一折，非空折测试失败。查看指标前改为稳定排序均衡分组，并增加精确映射、顺序不变性及三家族非空测试。协议和测试未按模型结果修改。

## 拟合与统计

每个外层 train 先去重，latest 是快照序号/时间最新，不是挑最高成绩。尺度、噪声、残差、prior 全部来自 train。层级池按不同玩家聚合，重复快照和高频玩家不额外增权。M4 只使用用户 OOF Personal 残差；训练校准的每个用户，其全部记录都在该次融合拟合中剔除。

额外的 heldout-label poison 测试把 y 改成极端值，确认所有模型的 point、quantiles、calibration、shrinkage 不变。还验证本人排除、未来特征拒绝、修订冲突、重复快照不增加 ESS、稀疏层级回退、无校准区间未知、M0 原始点不变。

点指标使用共同 M0 可评估集合；无历史导致的 M0 缺失单独计数，冷启动分布/误差为 null。分位数可评估记录和用户另计；没有训练校准不能生成零宽度“校准区间”。

Bootstrap 重采样整个用户簇，同一用户的谱面不按独立观测抽样。配对增益使用相同用户、目标、快照和修订。小于2名用户的分层 CI 为 null；没有相关谱面的 Recall/NDCG 为 null。仅 MAE 与 M4配对 MAE增益提供 CI，其他指标提供描述性汇总。

## 验证范围

本轮只执行新 Prediction/Artifact/Identity、M0重放/模型/泄漏/统计测试，候选 API 与 Vue 对照组件的目标链路验证，以及一次最终候选 Nuxt build。没有重跑 B3 Golden、B4-1 299、B4-2旧集成/回归、历史 Catalog 审计或数据库迁移。

全部 QA/build 经过现有内存 wrapper，串行取得共享维护锁。两次矩阵试运行在静态边界复核时主动停止；之后一次进程收到中断信号，wrapper 按 INTERRUPTED 归档并终止子进程。这些运行均未生成完整报告、不计为成功。修正包括稀疏样本和完整个人分布回退；没有查看未完成实验的模型指标或修改评估标准。最终完整运行证据与汇总见 acceptance.md。候选构建的可用内存准入后来由用户明确授权单次跳过；原脚本及其余隔离限制保留，最终完整构建通过。
