# Personal vs Cohort 结果

仅合成数据：60名合成玩家、12个目标谱面；792行含重复快照，去重720行，其中672行/56名用户有 M0，48行/4名冷启动用户明确不足。主配置固定 Rating/top24。

完整225行矩阵及分层、用户宏平均/记录加权、CI： [aggregate-results.json](aggregate-results.json)。协议和源文件哈希随报告保存。没有逐用户回测输出。
