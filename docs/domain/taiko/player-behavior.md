# Player Behavior

`PROJECT` 数据中的时间至少区分真实游玩/创PB时间、同步观测时间、手动编辑/导入时间、计算时间。Kinoko `2765-01-01`是手动导入标记，不是真实游玩日期、不作为成长事件。保留原字节与来源标记；不将其列为需要自动修复的未来数据异常。

`PROJECT` 有界时间段内没有可用观测，不证明没有游玩。接口失败、同步遗漏、换绑、导入、累计计数回退和模型变化分别记录。单次PB、近期稳定表现、历史最佳与最近练习是不同观察。重复请求失败也不能按次数计为丢失了同等数量的独立Measurement。

`EXPERIENCE` 玩家可能在冲分、全连、练习弱项、娱乐、解锁/称号间切换；偏好、可用时间和设备条件可能改变选曲。不要由一次成绩变化推断人格、动机或长期能力下降。

`HYPOTHESIS` 连续失败、疲劳、陌生谱面效应或练习迁移会影响结果，但现有数据不足以逐个解释。未来采集应允许玩家明确声明目标与反馈，并保存来源/不确定性；不能从只含最高分的历史还原每次尝试或真实游玩顺序。

Measurement已知事实：writer允许sampleCount0，reader要求正整数；失败可能发生在SQL upsert之前。`sampleCount`描述计算样本，不等于当天游玩次数。调查见[Measurement报告](../../catalog-release-batch2-20261124/integrity/measurement-report.md)。
