| 澄境执律 `dan_kanzui_red` | 赤金粹（mark2） | **回收，不沿用** | 与新的红色系定位重复，改用「赤之极处 / 赤之深境」一类 |
| 越境凌云 `dan_major_progress` | 段位晋升（observed grade 事件） | **归还 breakthrough flash，不进 matrix** | 它描述事件，而 overlay 描述 current-version standing |

## 5. 设计说明（对应产品要求）

- **段位 identity 唯一**：七段金虹「初虹」与达人金虹「天极回响」不共享任何字面；gold_rainbow 全列 初虹 → 層虹 → 凌霄貫律 → 極境無瑕 → 玄鋼無瑕 → 金名無瑕 → 超絶無瑕 → 天極の響 逐级升势。
- **family 语义**：red =「突破到这一高度」（越境 / 踏玄 / 留名 / 破人之壳 / 达人之门）；red_rainbow =「以赤色达标却零失误」；gold =「在这一高度稳定达到更高合格线」；gold_rainbow = 极限完成，自成一套意象（虹 / 无瑕 / 天极），不是 gold 的加强版。
- **不机械嵌段位名**：title 全为诗性身份，具体段位由 Evidence 承担；identity 由 (dan, family) 组合保证唯一。
- **Body 不复述 Evidence**：Evidence 陈述「段位 · 合格档」，Body 只留身份与余味。
