# 最小后续任务与决策

本页是计划，不是实施授权。所有任务基于当前0.81.10重新验收；发现问题未修复。

| 顺序/任务 | Gate/紧迫性 | 最小范围与验收 | 成本/权限/失败与回退 |
|---|---|---|---|
| R1 封闭成绩读取授权 | G2/P0 SEC-01 | 明确公开政策；接入目标用户授权或关闭入口；匿名/异主/撤销/路径异常在真实guard隔离负例全部拒绝，正常委托只读其目标 | 只用合成身份/目录；DB需test opt-in；禁止回退到匿名任意ID读取 |
| R2 补齐writer运行清单与提交合同 | G1/P0 DATA-01前置 | 登记Viewer、Wahlap/Hiroba、dispatcher、merged、manual/import、维护、日存档及reader；每项版本/锁/提交/恢复/监控有证据 | 跨仓库只读优先；权限不足列UNKNOWN，不能强行宣布清单完整 |
| R3 最小可恢复文件提交 | G1/P0 DATA-01 | 依R2选择A/B/C；所有writer共同协议、reader fence、同秒唯一、并发/故障/ENOSPC恢复，已提交不丢、未提交不伪装完整 | 先小合成、再守原IO/peak预算；兼容投影与回退方案独立批准，不能先迁DB再想合同 |
| R4 核验0.81.7语义与日存档生命周期 | G0/G1/P1决策 | 冻结旧日、当日更新、DF同份judgment证据、首屏类型覆盖、绑定切换/删除、补齐来源与备份；批准以新语义替代0.81.4对应验收 | 不重新施工Passport；仅缺陷独立切片；不重算/改生产历史 |
| R5 性能与SLO证据 | G3/P1 PERF-01 | 补真实受授权请求/日志计数、正式构建切换计数、current source SHA；旧3s/5s保留，peak可读，样本N充分 | 所有主动负载隔离；超guard停止，不能放宽预算换PASS |
| R6 恢复与部署一致性 | G4/UNKNOWN OPS-01 | DB+C/H+archive恢复包/校验/演练、RPO/RTO、代码回退点、源产物版本映射、告警送达 | 不生产restore；先合成，失败保留阻塞；发布权限另批 |
| R7 全站合同与RC执行 | G0/G6/UNKNOWN | 关闭P0后签字冻结真实公开范围；按RC矩阵执行，未测设备披露 | 官方build/浏览器串行memory runner；不擅自bump |
| R8 可衡量业务事件 | G5/P1观察欠账 | 精确业务成功去重、SPA、身份/退出/删除与分母，Web/Bot分列 | 本轮只设计；无留存目标硬阻断 |

P2 / 1.x：完整365天成绩事实、新Monthly/Session Recap、OAuth生态、额外高级画像。退出条件为来源可靠、数据安全和可解释口径准备好；不能把现有90天数据的恢复/身份风险挪入P2。

必要人工决定：R1授权政策与修复范围；R2跨仓库资产盘点权限；R3安全合同及路线；R4确认0.81.7排序规则取代旧“仅同质量带多样性”门槛；R5双SLO提案；R6恢复损失/时长承诺。无需为整理现有证据重复授权。
