# 1.17.0 — 后台工作台与活跃用户统计

后台工作台新增今日活跃用户、已登录与未登录拆分、近 7/30 天活跃，以及上传玩家人数。调整后台外壳、移动端导航、图表和最近操作展示。原有服务器页面请求 PV 与独立 IP 保留，继续采用最近 24 小时口径。

DAU 按北京时间自然日统计：合并当天经过共用会话认证入口的账号，与浏览器累计可见 5 秒或首次真实交互后上报的设备；设备关联账号后去重，排除标疑设备。账号活动包含 App 与相关接口请求，Bot 服务令牌和 Bot 指令次数没有接入该 DAU。上线前的匿名访问无法回填；会话种子只保留其最后活动日，历史账号数据不完整。

集成修正：

- 客户端确认入库成功后才保存当天标记；每页每标记最多尝试三次，失败间隔 15 秒重试。覆盖在途登录关联、跨日返回、重复导航与应用卸载清理。
- 同一 IP 前 20 台设备计入访客，第 21 台起标疑。数据库命名锁保证并发判断一致；设备计数最多读取 20 条索引记录。
- 信标接口最多同时处理 16 个请求，同一 IP 每分钟 60 次，限流桶最多 5000 个。暂时不可用返回 503，限流返回 429，无效请求忽略并返回 204。
- 修正机器请求总数混入接口、资源和普通错误的问题；仅合计已知自动化、扫描路径及疑似自动化。旧日志缺口在当前窗口已完整时不再误报；请求失败显示重试提示。
- 补齐新增 DAU SQL 测试的内容服务接口，以及既有登录回归测试缺失的称号表，均使用独立合成数据库。

需要显式执行 `taiko_viewer/scripts/migrate_user_activity_schema.ts` 创建 `web_user_daily_activity`、`web_daily_visitors` 并一次性导入会话种子。缺表不会阻断登录；工作台显示未统计。设备 ID 与 IP 仅保存 HMAC。

验证覆盖客户端插件、实际 H3 访问信标与账号请求、独立 SQL 迁移/重试/并发去重/历史窗口、原有访问日志统计、OIDC/账号和论坛回归，以及真实后台外壳与图表在 375/390/1440px 的布局和异常状态。生产发布后另执行可清理的专属账号/设备冒烟。
