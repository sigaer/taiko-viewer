# Viewer 0.85.0

本版本将 0.85.0-rc.8 已交付功能转为正式版，不新增接口、算法或授权能力。网站应用版本为 0.85.0，公开曲库的路径版本为 v1，计算响应的 model 仍为 v1；Contract 1.1 保持 FREEZE_CANDIDATE，未宣布冻结。

## Developer API 与接入指南

登录后的 `/account/developer` 提供中日文接口总览、字段、参数、cURL/Python 示例、JSON、鉴权和错误处理说明。所有可访问该页的已登录用户均可阅读；受保护数据仍要求已有且有效的 Developer Token。申请、状态、Token 掩码、登录保护和原授权管理能力保持不变，隐藏的旧版应用授权引导未恢复。文档展开、切换和复制均不自动调用业务 API。

| 能力 | GET 路径 | 第三方鉴权 |
| --- | --- | --- |
| 当前成绩 | `/api/developer/userdata/{userid}` | 已获批、有效的 Developer Token |
| 歌曲、谱面与难度 | `/api/v1/taiko/catalog/songs` | 公开，无需 Token |
| Rating 与六维 | `/api/developer/userdata/{userid}/rating` | 复用现有 Developer Token |
| 推荐游玩谱面 | `/api/developer/userdata/{userid}/recommendations` | 复用现有 Developer Token |

`{userid}` 为太鼓 Source ID，不是网站账号 ID。当前成绩只读来源中的现有字段，不提供成长历史、年度报告、同步或写入。Rating 保留综合值、六维及最多 30 个谱面详情，详情上限不等于聚合样本数。推荐保留现有排序与最多 20 项结果，不新增理由、提升分数或可调参数。完整字段及四个接口示例见 [接入指南](https://github.com/sigaer/taiko-viewer/blob/0.85.0/docs/developer-api-batch1.md) 和 [OpenAPI](https://github.com/sigaer/taiko-viewer/blob/0.85.0/docs/developer-api-batch1-openapi.yaml)。

## 目录迁移

- `/api/v1/taiko/catalog/songs` 默认一次返回完整曲库，无需查询参数；每首歌曲包含 charts。
- 原独立 `/api/v1/taiko/catalog/charts` 已移除，返回 404。
- 原 `?include=charts` 查询不再支持，返回 400；请直接请求 songs 路径。
- 沿用 rc.8 的精简目录 DTO：歌曲为 songId、song_name、song_name_jp、aliases、status、charts；谱面目录项仅含 difficulty 和 level；版本信息只在顶层 versions 出现一次。
- 从早期候选或严格旧 Schema 客户端迁移时，更新 `CatalogSongsResponse` 和生成绑定；不要继续把目录项当作内部 canonical Song/Chart。已使用 rc.8 精简 DTO 的客户端无需再改响应绑定。

`difficulty` 为难度档位：1 简单、2 普通、3 困难、4 鬼、5 里鬼；`level` 为星级。关联旧成绩使用 `String(record.song_no) === song.songId` 和 `record.level === chart.difficulty`。歌曲状态不代表逐地区、逐难度实装情况。曲名缺失为 null，别名可为 []，缺少的谱面不补造。

以下为合成数据，JSON 可直接解析；摘要使用合成占位值，实际请求返回真实摘要：

```json
{
  "versions": {
    "contractVersion": "1.1",
    "schemaRevision": "synthetic-schema-revision",
    "catalogRevision": "synthetic-catalog-revision"
  },
  "items": [
    {
      "songId": "10001",
      "song_name": "示例歌曲",
      "song_name_jp": null,
      "aliases": [],
      "status": "active",
      "charts": [
        { "difficulty": 4, "level": 9 },
        { "difficulty": 5, "level": 10 }
      ]
    }
  ]
}
```

公开曲库不发送 Authorization。主动附带的无效 Bearer Token 仍会被验证，不保证按匿名请求处理。

```sh
export TAIKO_API_BASE='https://viewer.sakura-bot.cn'
curl --fail-with-body --connect-timeout 5 --max-time 20 \
  "$TAIKO_API_BASE/api/v1/taiko/catalog/songs"
```

Python 依赖：`python -m pip install requests`。

```python
import json
import os
import requests

base = os.environ.get("TAIKO_API_BASE", "https://viewer.sakura-bot.cn").rstrip("/")
try:
    response = requests.get(base + "/api/v1/taiko/catalog/songs", timeout=(5, 20))
    response.raise_for_status()
except requests.HTTPError as error:
    raise SystemExit(f"HTTP {error.response.status_code}: check availability or limits") from None
except requests.RequestException:
    raise SystemExit("Network error or timeout; retry only a bounded number of times") from None
try:
    data = response.json()
except ValueError:
    raise SystemExit("Response is not JSON") from None
print(json.dumps(data, ensure_ascii=False, indent=2))
```

受保护请求使用环境变量和 Bearer 头，不在 URL 中传 Token；请将占位符换为已有授权的配置：

```sh
export TAIKO_API_BASE='https://viewer.sakura-bot.cn'
export TAIKO_SOURCE_ID='<YOUR_TAIKO_SOURCE_ID>'
export TAIKO_DEVELOPER_TOKEN='<YOUR_EXISTING_DEVELOPER_TOKEN>'
curl --fail-with-body --connect-timeout 5 --max-time 20 \
  -H "Authorization: Bearer $TAIKO_DEVELOPER_TOKEN" \
  "$TAIKO_API_BASE/api/developer/userdata/$TAIKO_SOURCE_ID"
```

分析接口示例使用连接 5 秒、读取 90 秒的客户端期限；现有服务端／网关期限仍可能更早结束请求。不要默认并发调用或无限重试。遇到 429 停止即时重试；503 按实际错误处理，必要时只做有限串行退避。

## 限制与回滚

本次没有改变 API 响应、Token 签发／撤销／鉴权、应用授权、数据库、生产配置、配额或资源限制。目录仍受 10000 歌曲及 JSON 8 MiB 等现有限制，超限返回 503，不返回截断目录。应用正式发布不代表整个 API 体系冻结。

发布使用现有受控构建与部署脚本，保留 `.output.previous` 回滚构建。生产验证使用既有受控账号／Token 串行只读访问，不创建或撤销授权，也不执行迁移。0.85.0 标签与非预发布 GitHub Release 仅在正式提交构建、部署和线上验收完成后创建。
