# Sakura Taiko Viewer 1.0.0

**My Taiko, in one place.**

首个1.0正式版收口现有产品能力，不新增数据模型、算法、服务端权限或产品功能。

## 玩家可以做什么

- **My Viewer**：登录、绑定和切换太鼓账号，查看歌曲、当前成绩、B30、六维与进度；同步后可直接查看当前成绩、成长档案，或进入推荐。完整成功、部分成功与失败分别反馈。My Taiko数据概览仍遵守既有灰度准入；其他账号保留原功能入口。
- **Community**：查找歌曲／谱面关联内容，发帖、回复、点赞、查看通知和自己的帖子；保留既有治理权限及失败重试。
- **Training**：使用今日计划或普通歌曲推荐，查看指定难度，通过Goal Preview和明确确认创建目标，在成长档案查看并使用既有评估和完成证据。推荐列表、预览和导航本身不创建目标。
- **Progress**：查看Recent／Daily、成长档案、Weekly及既有权限下的年度回顾和分享。同步后返回成绩／成长页面使用既有刷新信号；账号或绑定变化后，旧请求不能覆盖当前数据。

中日文与移动端继续使用现有页面和导航。0.88.3修复了歌曲别名导致My Taiko误报“绑定已变更”的问题，真实源漂移与绑定变化检查保持有效。

## Contract 1.1 正式冻结决定

2026年10月31日，依据维护者明确要求完成1.0.0、正式冻结Contract并接受剩余有限风险的发布指令，将现有 **Contract 1.1** 从FREEZE_CANDIDATE转为 **CONTRACT_FROZEN**。本文件是受控lifecycle的正式发布决定，不追溯改写此前候选或历史冻结记录。

- Schema唯一正本：`packages/sakura-taiko-contract/schema/contract-v1.json`，序列化revision保持 `30591840759a1d437e01f002f215a320673ce7ed95580d30f162756339c646db`；不修改Schema内容、生成绑定或SDK响应类型。
- 发布后启用该接口的宿主，其`GET /api/v1/taiko/meta`返回`status: CONTRACT_FROZEN`、`contractFrozen: true`；runtimeEnabled独立表示回应宿主的现有开关，不因冻结启用其他宿主或能力。
- 冻结现行完整有界目录、公开DTO、nullable／unknown、难度与星级、观察时间及事实语义。目录内容可正常更新revision，冻结不固定歌曲数量或成绩内容。
- 旧Developer Token当前成绩／Rating／推荐读取，与ResourceGrant的属主、绑定、client、scope、撤销及304前授权校验保持各自既有边界；history／growth scope继续不开放，不新增写入或同步权限。
- OpenAPI补正现有`account:read`能力、新版`viewer-account-consent-v2`与仍支持的旧同意格式。新版请求不允许客户端指定scope或有效期；旧格式的原范围与到期规则保留。此为文档匹配既有实现，不是扩权。

最小metadata字段示例（实际响应还包含当前revision和能力等字段）：

```json
{"apiVersion":"v1","contractVersion":"1.1","status":"CONTRACT_FROZEN","contractFrozen":true,"runtimeEnabled":true}
```

网站`1.0.0`、API路径`v1`、Contract`1.1`和计算模型`v1`分别管理。本次是现有能力的正式稳定发布，不引入破坏性接口迁移。当前有效文档为[四接口OpenAPI](../developer-api-batch1-openapi.yaml)、[ResourceGrant v1 OpenAPI](../083-developer-api-openapi.yaml)和[兼容承诺](../../taiko_viewer/public/docs/developer-api-compatibility.md)。对严格消费者不笼统承诺“新增字段一定兼容”；影响现有结构或语义的变更须显式版本、迁移与弃用说明。没有新sunset日期，不要求外部旧客户端全部迁移。

## 已知限制与明确接受的风险

- **已知Source单案暂缓处理**：保留既有损坏对象、committed hash不符和不可恢复旧revision的事实；没有证据确认该独立单案造成网站整体业务阻塞。维护者已明确决定不再由它自动阻断本次正式发布，停止主动推进W1、PR46、Source修复或协调器开发。本版本不修复或改写该对象，相关读取继续按既有完整性检查拒绝不可信数据，不以降级绕过。
- **恢复能力边界保持未验收**：不能据本版本宣称当前同代完整恢复、持续RPO≤15分钟或完整RTO≤120分钟已通过。旧verified点及受限恢复证据保留，诊断包不变为有效恢复点。此恢复缺口作为明确接受、独立维护的剩余风险记录，不在本次偷偷改变备份、调度、数据库权限或生产数据。
- **历史SSR归因未穷尽**：历史65次歌曲SSR500不追认全部同因。沿用已修复缺陷与限定生产窗口965次有效歌曲GET无4xx／5xx的证据，接受残余历史归因在后续维护跟进；新出现的实际业务故障仍按影响处置。
- **成长证据有范围**：冻结测量可选30／90／180／365天，可信成绩事实最多近90天；缺少记录不补零，同步不推定真实游玩。未玩或无可靠基线的推荐候选只提供浏览，不承诺能够创建／完成目标。
- Annual与My Taiko灰度、资源准入、队列、Worker上限及已接受的历史限制保持。完整365天成绩事实、OAuth生态、全站视觉重构与新增容量研究可后续安排，不成为本次新增前置事项。
