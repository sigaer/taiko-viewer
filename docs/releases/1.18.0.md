# 1.18.0 — 称号分类筛选

称号页新增活动、AI 对战、歌曲游玩、歌曲过关、歌曲全连、歌曲全良、组合称号和其他分类，并显示各分类数量。分类可与现有名称、条件和底板搜索叠加使用，切换分类或搜索时回到第一页；无结果时可一键重置全部筛选。继续每页最多显示 50 条称号。

分类根据现有获取条件和明确的歌曲底板类型计算，不改动称号资料、歌曲关联或官方目录。活动和 AI 条件优先识别，组合称号按多曲/限定单局挑战条件区分；同曲多个 ID 和多首任选其一的条件不据此归为组合。曲名内的关键词不参与获取方式判断，未知条件归入其他。新增中日文文案，分类按钮支持键盘和选中状态，手机端自动换行。

当前 861 条资料分布：活动 79、AI 对战 16、游玩 11、过关 91、全连 550、全良 82、组合 13、其他 19。分类随每日资料更新重新计算。

验证：分类边界和关键词测试 8 项、既有官方目录合并测试 6 项通过；使用真实列表组件与当前目录快照，在中日文、375/1440 像素、明暗主题共 4 种布局下验证分类计数、搜索叠加、分页归一、无结果重置、键盘选择、歌曲链接及无横向溢出。相关组件 scoped CSS 检查通过，临时浏览器和测试服务已关闭。发布后再对真实称号页执行浏览器验收。
