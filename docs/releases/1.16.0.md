# 1.16.0 — 称号歌曲 ID 索引与每日资料同步

近期歌曲称号虽已从官方条件提取曲名，Viewer 读取的本地称号资料仍没有歌曲关联。关系生成器现在同时记录歌曲 ID、官方称号 ID、按底板区分的发布记录及按歌曲 ID 的反向索引，保持原曲名关系和双向索引兼容。使用唯一的规范化中日文曲名匹配，无法确认的关系保留诊断，不猜测 ID。生成采用原子替换，失败保留原文件。

新增同步工具通过已有称号管理 API 新增缺失资料或合并歌曲 ID，并分页读回核对。官方称号 ID 与本地数据库 ID 分开处理，名称、底板、通关/全连/全良及表里谱分别匹配；既有人工条件和歌曲关联保留。缺失凭据、接口错误或读回不一致均失败退出，不重试结果未知的写入。每日编排由 taiko-bot 0.26.0 接入；配置方式见 `taiko_viewer/README.md`，凭据只放 Git 外的私有文件。

真实目录预演：原有 761 条曲名关系及其条件、难度、来源行号没有改变，新增 ID 字段及索引；709 条关系匹配到唯一 ID，15 条有同名歧义，37 条未匹配。形成 685 个完整的官方称号发布记录。对当前本地 API 的只读预演为新增 117 条、更新 0 条，51 个不完整或有歧义的发布记录跳过。预演不是实际写入完成的证据。

验证：关系生成及合成 HTTP 服务的 15 项测试通过，Viewer 原有称号读取/合并的 6 项测试通过。覆盖表里谱与底板隔离、手工资料保留、分页完整性、鉴权写入、重复执行、写入错误、写后读回及失败保留原文件。无新增界面文案。
