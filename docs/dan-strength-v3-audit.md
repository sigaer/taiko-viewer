## 3. Completion 模型：与 dan 交互（不再是固定 bonus）

```
strength = danBase[dan] + passClassBonus(dan, mark) + perfectionBonus(dan, mark)
         = danBase[dan] + bonus[dan][mark]      # 每个 dan 一组独立 bonus
```

三条曲线随段位变化（均由求解器在 canonical 约束下选出）：

- 金合格溢价 `goldPremium(dan) = (0.17 + 0.14·t)·danBase[dan]`（t 从七段 0 到达人 1）→ 七段 0.212 递增到达人 1.008
- 金粹金合格边际 `= 0.14 · goldPremium` → 七段 +0.030 到达人 +0.141（保持克制）
- 金虹合格边际 `= (0.60 + 0.10·t) · goldPremium` → 七段 +0.128 到达人 +0.705（显著跃升且随段位放大）
- 赤虹 `= 0.45 · goldPremium`；赤金粹 `= 0.10 · goldPremium`

## 6. 金虹 / 赤虹 的跨段位位置

| 金虹 | 对手 | 差值（正 = 金虹更强）|
|---|---|---|
| 七段 金虹 1.59 | 七段 金合格 1.46 | +0.13 |
| 七段 金虹 1.59 | 八段 赤合格 1.45 | +0.14 |
| 七段 金虹 1.59 | 八段 金合格 1.73 | -0.14 |
| 七段 金虹 1.59 | 九段 赤合格 1.65 | -0.06 |
| 七段 金虹 1.59 | 九段 金合格 2.00 | -0.41 |
| 八段 金虹 1.89 | 九段 金合格 2.00 | -0.10 |
| 八段 金虹 1.89 | 十段 赤合格 1.90 | -0.01 |
| 九段 金虹 2.21 | 十段 金合格 2.34 | -0.12 |
| 九段 金虹 2.21 | 玄人 赤合格 2.15 | +0.06 |
| 十段 金虹 2.62 | 玄人 金合格 2.69 | -0.07 |
| 十段 金虹 2.62 | 名人 赤合格 2.45 | +0.17 |
| 玄人 金虹 3.04 | 名人 金合格 3.11 | -0.07 |

要点：

- **七段金虹（1.59）跨过八段赤合格（1.45）**，逼近九段赤合格（1.65，差 -0.06），但**低于八段金合格（1.73）**。即「全良级别的低段位成果 ≈ 高 1–2 段的普通通过，但不等同高一段的金合格」。
- **八段金虹（1.89）≈ 十段赤合格（1.90，差 -0.01）**，仍低于九段金合格（2.00）。
- **九段金虹（2.21）跨过玄人赤合格（2.15）**，低于十段金合格（2.34）。
- **十段金虹（2.62）跨过名人赤合格（2.45）**，低于玄人金合格（2.69，差 -0.07）。
- 玄人金虹（3.04）同样逼近但不超过名人金合格（3.11）。

**设计张力（需产品定调）**：在「更高段位金合格不得被低段位金虹越过」的前提下，金虹的跨段位幅度被限制在「下一段的赤合格附近」。要让七段金虹达到玄人/名人级别的**一般成果**（即越过十段赤合格 1.90 甚至更高），要么放宽那条金合格支配规则，要么接受金虹在低段位被压得比玩家体感低。当前解选的是前者（保守）。
