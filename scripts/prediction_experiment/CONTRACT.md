Rows are synthetic internal dictionaries (not committed/uploaded):
`user`, `chart`, `family`, `snapshot` (int), `asOf` ISO, `visibleAt` ISO,
`profileCharts` list[str], `rating` float, `six` list[6 floats], `structure` list[3 floats],

`personal_fixture.generate()` returns `(rows, manifest)`; manifest has source commit / source tree hash / seed / fixed clock / target / revisions. Optional `generate(seed=...)`.

`validation.deduplicate(rows)` latest snapshot per (user, chart).
`validation.make_split(rows, kind, fold, folds=3)` -> `(train, test)`; kind cross-user, chart-family, combined. Test users never appear in train (even family holdout uses user embargo); family and combined hold out family labels. All snapshots user fold deterministic. Stable split assignment independent of outcomes.
`validation.audit_split(train,test)` -> dict with counts and violations, raises on leakage/profile-target/future/revision mismatch.
`validation.metrics(predictions, k=3, bootstrap=200, seed=4301)` -> aggregate JSON dict. Prediction dict adds `point`, `q25`,`q50`,`q75`,`covered` to row. Report user macro and record weighted point/quantile/interval/ranking metrics, rating/sparse/cold strata and user-cluster bootstrap MAE CI. No raw user IDs in returned report.
`validation.paired_gain(m0_predictions,m4_predictions,bootstrap=200,seed=4301)` -> paired user-cluster MAE improvement CI (positive = gain).
